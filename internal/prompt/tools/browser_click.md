Clicks an element of the page in the agent's tab: a button, a link, a tab, a checkbox. A visible cursor moves to it first, so the user can follow.

- `ref`: the element's ref from browser_read mode=interactive, such as `e12`; or
- `x` and `y`: a point on the latest screenshot, in its pixels (models that see images).

A click that would buy, pay, subscribe, join, donate, send, delete, post or comment, sign in, up or out, accept terms, grant access, like or report always asks the user first. Links off the allowed sites and CAPTCHAs are refused. The result says what was clicked and whether the page changed; read the page again to see it.
